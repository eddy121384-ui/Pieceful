# Pieceful

> **A quiet jigsaw puzzle that learns what you love.**

Pieceful 是一款以「安靜、低壓、長期陪伴」為核心的數位拼圖遊戲。

目前仍在 **Pre-production / Product Discovery** 階段。

## 核心產品承諾

> **No ads while you puzzle.**

免費玩家可以用廣告支持遊戲，但廣告不應在拼圖進行中打斷 Flow。

## 目前的產品方向

- 傳統 Jigsaw 核心玩法，規則簡單、低教育成本；
- **Puzzle Me**：把自己的照片變成拼圖；
- **Personalization**：逐步學習玩家喜歡的題材、視覺風格與難度；
- **Gentle Progression**：不靠 Rank / Battle Pass / 高壓 Streak，而以 Puzzle Journal、拼圖時間、收藏與回顧形成長期進展；
- **Local-first**：優先不需要帳號、不上傳私人照片、不依賴後端；
- 一次性 **Remove Ads** 作為主要付費方向之一；
- 目標是一人公司可長期維護的 **evergreen cash-flow game**，不是 Live Service。

## V1 原則

V1 先驗證：

1. 拼圖操作是否真的舒服；
2. 玩家是否會完成、回來、繼續下一張；
3. Puzzle Me 是否有使用價值；
4. `No ads while you puzzle` 是否能建立更高的信任與留存；
5. 個人化推薦是否能提高「看到圖 → 想開始拼」的比例；
6. Puzzle Journal 是否能形成低壓但可見的長期 Progress。

## 不做的事

V1 不做 PvP、排行榜、帳號社群、雲端同步、故事模式、3D 博物館、Battle Pass、體力、抽卡、Runtime AI 與高維護 Live Ops。
