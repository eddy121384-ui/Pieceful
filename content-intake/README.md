Place local batches under this directory, each containing `batch.json` and
approved PNG/JPEG source files. This directory is deliberately excluded from
Godot imports. Intake images and private paperwork are not committed; promoted
artwork is copied byte-for-byte to `assets/catalog/` by the pipeline.

See [the pipeline guide](../docs/CATALOG_CONTENT_PIPELINE.md) for the contract,
rights records, dry runs and recoverable batch promotion.
