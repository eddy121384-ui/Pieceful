# Piecepace V0-01 本機測試清單

目標：在實際 Godot 4.x 環境快速判斷核心拼圖垂直切片是否成立，並驗證新版 Procedural Classic Die-Cut Generator 是否真的開始像實體拼圖。

## 啟動

- [ ] Godot 可識別 repo 根目錄的 `project.godot`。
- [ ] 首次 import 完成後沒有 script parse error。
- [ ] `main.tscn` 可作為 Main Scene 執行。
- [ ] 畫面顯示中央淡色完整圖與左右兩側 12 片拼圖片。

## 拼圖片生成 — Classic Die-Cut

- [ ] 12 片皆有原圖內容，不是純色或 UV 拉花。
- [ ] 外框四周保持真正的平邊，整張完成後仍是矩形。
- [ ] 內部切線不是完美筆直格線：交點有輕微偏移、線段有輕微自然彎曲。
- [ ] 每條內部切線的 tab / slot 位置、胖瘦、深度與圓弧有可見差異。
- [ ] tab 有明顯的「窄脖子 + 圓頭」輪廓，而不是三角、鋸齒、正弦波或水滴形。
- [ ] 相鄰兩片共用同一條切線，凸凹輪廓 100% 對得起來，不應看到縫隙或重疊錯位。
- [ ] 12 片 silhouette 看起來彼此不同，不像同一模板只換凸凹方向。
- [ ] 切線沒有自我交叉、尖刺、異常小碎角或飛出去的 polygon。
- [ ] 拼圖片陰影與細框可辨識，但沒有明顯遮住原圖。

## 操作

- [ ] 滑鼠可點住並拖曳每一片。
- [ ] Touch 裝置可用單指拖曳。
- [ ] 拖曳中的 piece 會浮到其他 pieces 上層。
- [ ] 放開後 piece 留在玩家放下的位置。
- [ ] 靠近正確位置時 piece 會吸附到 target。
- [ ] 已吸附 piece 不再被拖走。

## 完成

- [ ] 每吸附一片，頂部計數正確增加。
- [ ] 完成 12 / 12 後只出現一次 `Puzzle complete`。
- [ ] 完成後所有共享切線在視覺上對齊。
- [ ] `Play again` 可重新開始。
- [ ] `Reshuffle` 可在未完成時重開一局。

## 若失敗，優先回報

請依序提供：

1. Godot 版本（例如 4.6.3 stable）。
2. Debugger / Errors 第一個紅色錯誤全文。
3. 若沒有錯誤但畫面不對，提供整張遊戲畫面截圖。
4. 描述是 `啟動失敗 / 刀模形狀怪 / UV 顯示錯 / 拖不了 / snap 錯 / completion 錯` 哪一類。

不要一次修多個問題；先修第一個阻塞錯誤，再重新 Run。
